# 房补通勤规则口径｜commute-r1.0

## 事实

- 不同公司规则可能不同，本版本只执行用户在页面输入的时间阈值。
- 系统算路不能替代公司最终认定；所有推荐都需要回地图 App 复核。

## 合法路线白名单

| 模板 | 说明 | 使用阈值 |
| --- | --- | --- |
| `walk` | 纯步行 | `walk_max_min` |
| `bike` | 纯骑行 | `bike_or_subway_max_min` |
| `subway` | 地图 App 给出的端到端地铁方案，可包含 App 内置接驳步行 | `bike_or_subway_max_min` |
| `bike->subway->bike` | 两端骑行接驳，中间地铁 | `mixed_max_min` |

不在白名单中的拼接模板不能判为合规。模板合法且总时长不超过对应阈值，才通过系统规则。

## 状态与指标

- `no_route`：没有获得路线。
- `route_found_noncompliant`：有路线，但模板或时长不满足规则。
- `compliant_boundary`：合规且余量 0–2 分钟，必须强调临界风险。
- `compliant_clear`：合规且余量大于 2 分钟，仍需地图复核。
- “有效测距完成”：系统合规 + 地图复核一致 + 截图方案可用。
- “错误合规”：系统判为合规，但复核后标记最终没有合规方案。

每次结果必须记录 `rule_version`。规则内容变化时创建新版本，不覆盖历史解释。
