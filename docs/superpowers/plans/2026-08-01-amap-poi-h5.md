# Amap POI H5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将房补通勤工具改成仅保留公司地点与租房小区两个输入框的高德主算路 H5，并支持模糊搜索候选下拉。

**Architecture:** 前端只维护两个搜索框和候选选择状态；后端新增高德候选搜索与自动地点解析能力，统一返回真实 POI、直达路线和自动识别的地铁接驳组合。旧的手填门口、楼栋别名、候选地铁站链路整体下线。

**Tech Stack:** 原生 HTML/CSS/ES Modules、Python `http.server`、高德 Web Service API、`unittest`、Node test runner
