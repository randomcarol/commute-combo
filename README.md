# Commute Combo｜房补通勤组合搜索器

> 输入公司地点、候选房源和房补规则，自动比较原始地点、同名门口 / 楼栋别名、地铁出入口与合法通勤组合，输出可回到地图 App 复核和截图的候选方案。

## 用户问题

房补边界房源不能只看一条默认导航。用户往往要反复更换门口、办公楼别名、地铁出入口和通勤方式，再逐段截图。这个过程慢、容易漏试，也很难复盘为什么某条路线被推荐。

## 核心差异

- 比较原始地点与同名派生别名，不使用无关附近 POI 偷换起终点。
- 只把规则白名单中的路线判为合规；“地图返回路线”与“符合公司规则”分开统计。
- 解释别名节省分钟数、被规则排除的路线与必须回到地图 App 复核的步骤。
- 用 `request_id` 串联搜索、结果展示、地图复核和反馈。
- 用“单人重复任务实验”和“地址样本基准测试”积累证据，不虚构用户或上线数据。

## 产品流程

1. 输入公司地点、房源与公司规则，选择数据环境。
2. 高德解析 POI；比较原始点、同名门口 / 楼栋别名及地铁出入口。
3. 对合法模板排序并分别标记：未合规、临界合规、明确合规。
4. 展示推荐理由、候选分钟差、规则排除原因和截图清单。
5. 回到地图 App 复核，并按 `request_id` 记录一致性、问题和截图可用性。
6. 用匿名 `CASE-001` 等编号记录人工搜索与工具搜索的配对实验。

## 当前统一规则

规则版本 `commute-r1.0`：

- 合法模板：纯步行、纯骑行、地图端到端地铁、骑行 → 地铁 → 骑行。
- 默认阈值：步行 30 分钟；骑行 / 地铁 20 分钟；混合路线 20 分钟。
- 余量 0–2 分钟为“临界合规”，余量大于 2 分钟为“明确合规”。两者都必须回地图 App 复核。
- 有路线但模板不合法或超出阈值，不能计为产品成功。
- 核心指标“有效测距完成率”要求：系统合规、地图复核一致、截图方案可用。

完整口径见 [产品规则](docs/product-rule-v1.md)。

## 实验与指标

当前没有真实用户量、访谈结论、上线指标或 A/B 结果。研究设计是作者本人对同一批真实地址执行人工与工具配对搜索；公开数据只保留匿名案例编号和聚合结果。

现在可计算：有效测距完成率、路线返回率、系统合规率、错误合规率、Top-1 有效方案命中率、人工一致率、最优结果分钟差、任务耗时变化、别名有效案例数、P50/P95 搜索延迟与地图请求次数。没有 CASE 记录时页面显示 0 或 `-`，不生成结论；少于 20 个案例时固定提示“样本量较小，仅用于探索性验证”。

## 截图与演示

仓库暂不放入含真实家庭 / 公司地址的截图。建议录制时使用虚构地点或对地址做遮挡，并依次展示：首页输入 → 推荐解释 → 地图复核 → 实验看板。

## 项目局限

- 当前主要依赖高德；百度 / 腾讯仅用于有限 fallback。
- 候选池是高价值启发式搜索，不是无限穷举。
- 地图端到端结果、公司具体认定口径和截图接受程度必须人工复核。
- Python `ThreadingHTTPServer` 适合本地和小规模演示，不是高并发生产架构。
- 单人重复任务实验只能支持探索性判断，不能外推成真实用户结论。

## 本地运行

复制示例配置并在本地填入密钥（不要提交 `.env`）：

```bash
cp .env.example .env
COMMUTE_PROVIDER_MODE=mock python3 backend/server.py
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)，数据看板在 `/stats`。实时模式需在当前 shell 提供 `COMMUTE_PROVIDER_MODE=live` 与 `AMAP_WEB_KEY`。作者实验时把首页“数据环境”改为 `self_test`。

测试：

```bash
PYTHONDONTWRITEBYTECODE=1 COMMUTE_ENVIRONMENT=test python3 -m unittest discover backend/tests -v
/Users/dengzhilei/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node --test app/*.test.js
```

## 数据与 GitHub 安全

- 完整地址只在一次搜索请求中用于算路；埋点仅保存 SHA-256 截断哈希。
- 原始 JSONL、SQLite、实验记录和本地地址源文件写入 `local-data/` 或环境变量指定的本地路径，并被 `.gitignore` 排除。
- `.env.example` 只有变量名和说明，不含密钥。
